# Keks-To-Do für GitHub Pages 🍪

Diese Version verwendet den bunten Keks als festes App-Icon und Standardmaskottchen.
Das Einhorn erscheint ausschließlich, wenn das freigeschaltete Theme **Einhornland** aktiv ist.

## Enthalten
- Montag bis Sonntag
- Keksbelohnung nur am passenden Wochentag
- automatischer Wochenwechsel am Montag beim ersten Öffnen
- alle bisherigen Themes und Keksshop
- geheimes Einhornland-Theme
- Erfolge, Statistik, Sounds und `.keks`-Backups
- Offlinebetrieb als PWA
- keine PDF-Funktion

## Auf GitHub hochladen
1. Den Inhalt dieses Ordners öffnen.
2. Im vorhandenen Repository **Add file → Upload files** wählen.
3. Alle Dateien und den Ordner `icons` hochladen.
4. Gleichnamige Dateien ersetzen und **Commit changes** anklicken.
5. Ein bis drei Minuten warten.

Die Dateien `index.html`, `app.js`, `styles.css`, `manifest.webmanifest` und `service-worker.js` müssen direkt im Hauptverzeichnis liegen.

## iPhone-Icon aktualisieren
1. Bei Bedarf vorher ein `.keks`-Backup exportieren.
2. Das alte Home-Bildschirm-Symbol löschen.
3. Die GitHub-Pages-Seite in Safari öffnen und neu laden.
4. **Teilen → Zum Home-Bildschirm** wählen.

Das installierte Symbol bleibt immer der bunte Keks. Im Einhornland ändert sich nur das Maskottchen innerhalb der App und das Browser-Tab-Symbol.

## Version 3.1 – Ruhige Themenwelten

Unter Einstellungen gibt es jetzt **Animationen** mit drei Stufen:

- **Aus:** keinerlei Bewegungen oder Übergänge.
- **Dezent (Standard):** keine dauerhaft herumfliegenden Elemente; kurze Effekte nur bei erledigten Aufgaben, Erfolgen und Themewechseln.
- **Voll:** alle ursprünglichen Themenanimationen.

Bestehende Installationen starten nach dem Update automatisch mit **Dezent**.
